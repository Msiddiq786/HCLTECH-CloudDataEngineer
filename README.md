
# Cloud Data Engineering Portfolio

Hands-on portfolio demonstrating SQL analytics, PySpark data processing,
Linux automation, and cloud engineering with AWS and Microsoft Azure.

## Technologies

- SQL: joins, window functions, aggregations, query optimization
- Python and PySpark: data cleaning, DataFrames, joins, analytics
- Linux: log analysis, Bash scripting, system troubleshooting
- AWS: S3, IAM, EC2, CloudWatch, Lambda, Step Functions, SNS
- Azure: Data Lake Storage Gen2, Azure RBAC, Virtual Machines,
  Azure Data Factory

## Projects

### 1. SQL Analytics
- Employee and department analysis
- Sales revenue and monthly trends
- Window functions and query optimization

### 2. PySpark Data Processing
- DataFrame creation and filtering
- CSV validation and duplicate removal
- Missing-value handling and revenue aggregation
- Customer and order joins

### 3. AWS Secure Data Processing
- Private S3 storage and IAM access policies
- EC2 monitoring using CloudWatch alarms
- Event-driven processing with Lambda
- Workflow orchestration with Step Functions

### 4. Azure Data Integration
- Azure Data Lake Storage Gen2
- Identity and role-based access control
- Virtual machine connectivity troubleshooting
- Data Factory pipeline design and monitoring

## Repository Structure

- `sql/` — SQL scripts
- `linux/` — Bash scripts and Linux commands
- `pyspark/` — PySpark programs
- `aws/` — AWS configurations and workflow definitions
- `azure/` — Azure implementation guides
- `datasets/` — Safe sample datasets
- `screenshots/` — Evidence of testing and configuration

## How to Use

1. Clone this repository.
2. Install the tools required for the relevant project.
3. Follow the README in each project folder.
4. Run the scripts with the provided sample data.
5. Compare your results with the documented expected output.

## Security

No cloud credentials, passwords, private keys, or confidential data
are included in this repository.

## Learning Goals

Build practical skills in data engineering, cloud security,
data processing, monitoring, and workflow automation.
